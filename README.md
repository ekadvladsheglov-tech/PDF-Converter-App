# 📄 PDF Converter App (Desktop)

Простой, быстрый и полностью локальный десктопный конвертер PDF-файлов с графическим интерфейсом. Никаких облаков, никакой отправки данных на сервер — всё работает прямо на вашем ПК.

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Возможности

* 🔄 **PDF в Word** — качественная конвертация с сохранением разметки.
* 🔄 **Word в PDF** — быстрая конвертация текстовых документов.
* ✂️ **Разделение PDF** — разбивает многостраничный PDF на отдельные файлы (по 1 странице).
* 🔗 **Объединение PDF** — склеивает несколько PDF-документов в один.

## 🚀 Как использовать (для обычных пользователей)

1. Перейдите в раздел **[Releases](../../releases)** (если вы загрузите туда .exe).
2. Скачайте последнюю версию `PDF_Converter.exe`.
3. Запустите файл. Установка Python или других программ **не требуется**.
